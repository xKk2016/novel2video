## 一、v2 到底哪里不行（重写的依据）

| # | 问题 | 证据 | 后果 |
|---|---|---|---|
| 1 | **全程零音频描述** | 57 条提示词里没有一条写声音 | H3 是原生音视频同步模型（工作流模板带 `VAEDecodeAudio`），不写声音等于白扔一半能力。原文明明有「山风吹得血袍如战旗般嚯嚯作响」「额头碰地板的砰砰声」「细雨打窗扉的微微声响」，一条都没用上 |
| 2 | **风格串逐字重复 8 个标签** | 每条开头都是同一串 130 字符的画风标签 | 占掉每条提示词约 1/3 的注意力预算，对画面内容零贡献 |
| 3 | **运镜写成句尾标签** | `slow push-in` / `very slow push-in` 堆在末尾 | 违反 H3 官方规范（镜头运动应写成镜头内的自然动作句），模型对镜头的响应变弱 |
| 4 | **动作是静态快照** | 如镜3「thrusting his longsword forward, sneering」 | 只有一个瞬间，模型不知道该从哪到哪、结束在什么状态，容易动作做一半卡住 |
| 5 | **说话人没有稳定音色档案** | 群雄甲/乙/丙/丁 描述随镜变化 | 同一角色跨镜音色漂移，观众分不清谁在说 |
| 6 | **参考图绑定笼统** | `the same young man as in <Picture 1>, <Picture 2>…` | 只罗列不说明每张图锁定什么，模型遵循度低 |
| 7 | **原文细节大量浪费** | 「数百道伤口涌血」「脚下积一大滩血水」「苍白脸被晚霞映照」「赤铜香炉香烟袅袅」等 | 提示词笼统，画面没有信息量 |
| 8 | **光线描述零散** | 只有个别镜写了 rim light | 没有逐镜明确光位，同场光向会漂 |

## 二、v3 改了什么

| 项 | v2 | v3 |
|---|---|---|
| 音频层 | 无 | **57/57 镜**，每镜写环境音 + 动作同步音效 |
| 风格串 | 8 个标签 / 约 130 字符 | 3 个标签 / 约 40 字符 |
| 运镜 | 句尾标签 | 写成镜头内的自然动作句 |
| 动作 | 静态瞬间 | 写明起止状态与过程 |
| 光线 | 零散 | 每镜一条明确光线（对齐官方光线库） |
| 说话人 | 无稳定档案 | 16 个角色固定音色 + 稳定 ID（S1–S16） |
| 对白句式 | 画内/画外混用 | 旁白走官方画外音句式（声明画内角色嘴唇闭合），其余画内 |
| 配角识别 | 袍色 + 年龄 | 袍色 + 年龄 + 固定面部/发型特征 |
| 环境注入 | 分镜写一遍 + 锚再注入一遍 | 分镜自带完整环境，文字锚跳过（图锚照常） |
| 中文字段 | 无 | 每镜新增画面中文对照 + 中文音频对照 |
| 死字段 | 生成 `first_frame_prompt` / `last_frame_prompt` | 不再生成（chain 主线从不读取） |

## 五、实际生成片段的抽帧核验（最有价值的一条）

`output/clips/` 里有两条真实片段（`shot_001.mp4` 1.6 MB / `shot_002.mp4` 0.9 MB，均为 5.88 秒），是 v2 分镜实际跑出来的。抽帧看了：

| 镜 | 结果 | 说明 |
|---|---|---|
| 镜 1（大远景空景） | **基本到位** | 灰白山巅、暗红血泊、燃烧的云层、远处青山都在，构图与光向正确 |
| 镜 2（过肩镜） | **翻车** | 画面里出现**三个人**：左前景一个血衣背影、画面正中一个**正面黑衣男子**、远处石台上一个白袍人。本应是「方源背影在前景 + 白袍修士在对面喊话」两人才对 |

**根因（两条叠加）**：

1. **背影镜照样挂了 4 张正面参考图**——`_refs_for()` 只按场次取图，分镜里的 `ref` 字段从来没生效过。模型拿到正面参考图，就在画面正中照着补了一张正脸。
2. **正面外貌串被注入**——主角镜会追加 `lean narrow face / sharp half-lidded eyes / pale skin` 这类正面特征，进一步把模型往「画正脸」推。

**已修**：

- `_refs_for()` 现在尊重分镜的 `ref` 字段：`back` 只喂背面图（镜 2 的参考图从 **5 张降到 2 张**）、`face` 只喂面部特写。
- 所有 `ref=back` 的镜自动改用**背面口径外貌串**（`viewed from behind… no face and no eyes in frame`），覆盖 config 的正面外貌串。
- 镜 2 的构图描述改为「相机在他身后、越过他的背朝前看，**画面里只有他的背面**，对面的白袍修士**面向镜头**」，不再用容易歧义的 `Over-the-shoulder` 一句带过。

> 这条修复不只作用于镜 2：全片所有背影/过肩镜（镜 2、11、12）都会走新逻辑。

## 六、跑之前要知道的三件事

**① 服饰与原文不符（未改，需你定）**

小说原文写方源「一身残破的**碧绿**大袍」，但已生成的三视图锁的是**全黑**长袍（`refs/threeview_adult.png` / `threeview_youth.png` 都是黑的），`config.json` 的 `costume.default` 也写的是 black。v3 沿用了**已锁定的黑色**——改色意味着三视图要重画、已跑片段全废。要忠于原文就得重做视觉资产，你定。

**② 群雄四个配角走 T2V，脸只能靠文字钉**

这几位不是主角，没有三视图参考图，`anchor_mode=prompt` 会走 T2V 纯文字生成。v3 已给每人写死稳定识别特征（花白浓须 / 高髻 / 长白须 / 木簪束发），但**要彻底稳定只能补三视图**。

**③ 音频层与背影镜修复都依赖新版 runner**

v3 的音频层靠 `novel_to_video.py` 的 `_with_audio()` 注入，背影镜收窄参考图靠 `_refs_for()` 新增的 `ref` 支持——两处都在本次改动里。用旧版 runner 跑 v3，会**丢掉全部声音描述**，并让背影镜重新拿到正面参考图。
